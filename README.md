# java-calculator-precourse
[기능 목록 정리]
1. 사용자에게 값(문자열)을 입력 받는다. <br>
  1-1. 숫자는 양수여야 한다.<br>
   ex) 덧셈할 문자열을 입력해주세요. <br>
2. 구분자(쉼표, 콜론)를 식별한다. <br>
  2-1. 구분자를 바탕으로 각 숫자들을 분리한다. <br>
  2-2. 분리한 숫자들을 정수형으로 변환한다. <br>
  2-3. 변환한 숫자들을 더한다. <br>
3. //와\n 사이에 값(문자열)을 입력하면 나만의 구분자가 될 수 있도록 한다.(2번 참고) <br>
4. 잘못된 값을 입력하면 알려준다. <br>
   4-1. 잘못 된 값 입력 후 종료한다.<br>
5. 결과를 출력한다. <br>
   ex) 결과 : <br>
